## PowerShell 调 API 中文乱码（诊断完成，只读验证）

- 现象：`Invoke-RestMethod http://127.0.0.1:8000/api/v1/auth/me` 返回 `display_name : è¯¾ç¨ç®çå`（应为"课程管理员"）
- 根因：**客户端解码问题，非数据问题**。FastAPI 响应头为 `Content-Type: application/json`（不含 `charset=utf-8`），Windows PowerShell 5.1 对无 charset 的 JSON 默认按 ISO-8859-1 解码，导致 UTF-8 中文字节被显示为西欧重音字符。
- 证据：用 `api/.venv` 的 Python(urllib) 请求同一接口，HTTP 200，原始字节 `\xe8\xaf\xbe\xe7\xa8\x8b\xe7\xae\xa1\xe7\x90\x86\xe5\x91\x98`，UTF-8 解码后为 `"display_name":"课程管理员"`，数据完全正确。
- 解决方案（已告知用户，未改代码）：
  1. 换工具：浏览器 `/docs`、Python、Postman；
  2. PowerShell 手动纠偏：`[System.Text.Encoding]::UTF8.GetString([System.Text.Encoding]::GetEncoding('ISO-8859-1').GetBytes($r.Content)) | ConvertFrom-Json`；或改用 PowerShell 7 (pwsh)；
  3. 治本（待用户确认）：让 FastAPI 响应带 `charset=utf-8`。
- 备忘：`/api/v1/auth/me` 返回字段含 id/email/display_name/role/status/permissions(can_read/can_edit/can_manage_users)。
